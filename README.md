# 🌦️ Weather Service App

A Java-based console application that retrieves real-time weather information using a public Weather API. The application demonstrates Core Java concepts, Object-Oriented Programming, REST API integration, JSON parsing, and the Java Collections Framework.

## 🚀 Features

- Retrieve real-time weather information by city
- Display temperature, humidity, wind speed, pressure, and weather conditions
- Search multiple cities during a single session
- Maintain recent search history
- Exception handling for invalid input and API errors
- Modular project structure following OOP principles

## 🛠️ Technologies Used

- Java
- REST API
- HTTP Client
- JSON Parsing
- Object-Oriented Programming (OOP)
- Java Collections Framework

## 📁 Project Structure

```
WeatherApp/
│
├── Main.java
├── Weather.java
├── WeatherService.java
├── APIClient.java
├── SearchHistory.java
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA or Eclipse.
3. Configure your Weather API key (if required).
4. Compile and run `Main.java`.
